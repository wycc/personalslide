#Slide 41｜線性空間是什麼？

線性空間是一群向量的集合。

它滿足兩件事：

向量相加後仍在空間中
向量乘上純量後仍在空間中

例如：

平面上的所有二維向量形成 R
2
三維空間中的所有向量形成 R

#Slide 42｜為什麼 ML 需要線性空間？

因為資料被表示成向量。

模型會在向量空間中：

找最近的點
找分界線
找資料主要方向
找最佳投影
找最佳參數

例子：

KNN：在空間中找最近鄰居
Linear regression：在空間中找最佳投影
SVM：在空間中找最佳分隔超平面
PCA：在空間中找變異最大的方向

#Slide 65｜Learning Rate 的影響

Learning rate 太小：

每次更新很少
收斂很慢

Learning rate 太大：

可能越過最低點
loss 震盪甚至發散

Learning rate 是機器學習與深度學習中非常重要的超參數。

#Slide 66｜Batch GD、SGD、Mini-batch GD

Batch Gradient Descent：

每次使用全部資料
穩定但慢

Stochastic Gradient Descent：

每次使用一筆資料
快但震盪大

Mini-batch Gradient Descent：

每次使用一小批資料
深度學習最常用

#Slide 67｜為什麼 Mini-batch 適合深度學習？

假設有 100 萬張圖片。

每次用全部資料算梯度太慢
每次只用一張圖片又太不穩定
所以通常一次用 32、64、128 張圖片

GPU 可以高效處理矩陣運算。

因此 mini-batch 是效率與穩定性的折衷。

#Slide 68｜線性代數如何連到神經網路？

神經網路中的一層通常是：

這本質上是矩陣乘法。

如果加上非線性函數：

h=σ(Wx+b)

就成為神經網路的一層。

因此：

線性代數負責資料轉換
微積分負責梯度
最佳化負責訓練模型

#Slide 69｜為什麼需要 SVD/PCA？

真實資料通常是高維的。

例如：

一張 28×28 圖片有 784 維
一篇文章的詞彙向量可能有上萬維
醫學影像特徵可能有數千維

但資料真正重要的變化，可能集中在少數方向上。

SVD/PCA 就是用來找這些主要方向。

#Slide 70｜SVD 是什麼？

Singular Value Decomposition：

X=UΣV
T

其中：

U：輸出空間的正交方向
Σ：奇異值，代表每個方向的重要性
V：輸入空間的正交方向

SVD 可以幫助我們理解資料矩陣的結構。

#Slide 71｜SVD 的幾何意義

一個矩陣轉換可以拆成三件事：

先旋轉座標系
沿不同方向拉伸或壓縮
再旋轉到新的座標系

奇異值越大，代表該方向越重要。

奇異值很小，可能代表：

雜訊
不重要的變化
資料中較弱的方向

#Slide 72｜SVD 的機器學習用途

SVD 常用於：

降維
去雜訊
找資料主要方向
壓縮資料
推薦系統中的矩陣分解
解 least squares 問題
分析資料矩陣的 rank
分析模型權重矩陣

#Slide 73｜PCA 的核心問題

PCA 要回答：

資料中最重要的變化方向是什麼？

PCA 會找：

第一主成分：資料變異最大的方向
第二主成分：與第一主成分正交，且解釋剩下最多變異的方向
第三主成分：與前面方向正交，且繼續解釋剩下的變異

假設資料包含：

體重

通常身高高的人，體重也較高。

資料點可能沿著某個斜方向分布。

PCA 會找出這個主要方向。

第一主成分可能代表：

整體體型大小

第二主成分可能代表：

相對胖瘦

#Slide 75｜PCA 例子：影像資料降維

一張 28×28 灰階圖片有 784 個像素。

每張圖片可以看成 784 維向量。

PCA 可以找出主要變化方向，例如：

數字傾斜方向
上下左右位置變化
整體亮度差異

用較少維度保留大部分資訊。

#Slide 76｜PCA 和投影的關係

PCA 找一個低維子空間。

把資料投影到這個子空間後，希望資訊損失最小。

所以 PCA 也是一種投影問題。

與 linear regression 的共同點：

都在找子空間
都使用投影
都希望誤差最小
