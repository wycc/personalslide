Slide 02: 推薦系統的基本問題
投影片內容

推薦系統想回答的問題：

使用者還沒有看過哪些電影，但可能會喜歡？

例如：

使用者	已看過的電影
User A	The Dark Knight Rises、Memento
User B	The Dark Knight Rises、Memento、The Triplets of Belleville
User C	Harry Potter、Shrek

問題：

User A 尚未看過 The Triplets of Belleville，是否應該推薦？

說明重點

推薦系統不是只推薦熱門電影，而是根據每個人的過去行為做個人化推薦。

如果 User A 和 User B 的觀看紀錄很相似，而 User B 看過某部 User A 沒看過的電影，系統就可以推測 User A 也可能喜歡那部電影。

Slide 03: Collaborative Filtering 的直覺
投影片內容

Collaborative Filtering 的核心想法：

相似使用者可能喜歡相似的物品。
被相似使用者喜歡的物品，也可能值得推薦。

Google 教材指出，collaborative filtering 會同時利用 user 與 item 的相似性來做推薦，而且 embedding 可以由資料自動學習，不必完全依賴人工設計特徵。

說明重點

Collaborative filtering 和 content-based filtering 不同。

Content-based filtering 比較像是：

你喜歡這部動作片，所以推薦另一部動作片。

Collaborative filtering 則比較像是：

和你興趣相似的人喜歡這部電影，所以你也可能喜歡。

這使得 collaborative filtering 有機會產生比較意外的推薦結果，也就是 serendipitous recommendation。

mn

個數值，矩陣分解後只需要：

mk+nk

個數值。

當 k 很小時，可以大幅降低儲存與計算成本。

Google 教材也指出，matrix factorization 通常比完整矩陣更精簡，因為 embedding 維度 d 通常遠小於 user 與 item 數量。

Slide 28: WALS 與線性代數
投影片內容

WALS：Weighted Alternating Least Squares

步驟：

固定 user embedding U，求 item embedding V。
固定 item embedding V，求 user embedding U。
重複直到 loss 收斂。

Google 教材指出，WALS 每個階段都可以透過解線性系統完成，而且每一步都會降低 loss。

說明重點

這裡可以連結到線性代數課程中的：

least squares
normal equation
linear system
iterative optimization

原本同時求 U 和 V 很困難。

但固定其中一個矩陣後，另一個矩陣的求解就變成最小平方法問題。

Slide 30: Collaborative Filtering 的優點
投影片內容

Google 教材整理的優點包括：

不需要大量 domain knowledge。
embedding 可以自動學習。
可以產生意外但有價值的推薦。
只用 feedback matrix 就能作為推薦系統起點。
可以作為 candidate generator 的其中一種方法。
說明重點

Collaborative filtering 的力量在於：

它可以透過群體行為發現使用者自己也未必明確知道的興趣。

例如使用者未必會說自己喜歡某類藝術片，但如果相似使用者都喜歡某部電影，系統仍可能推薦它。

Slide 31: Collaborative Filtering 的限制
投影片內容

Google 教材指出幾個限制：

Cold-start problem
新使用者或新物品缺乏互動資料，難以建立 embedding。
不容易整合 side features
例如年齡、地區、電影類型、文字描述等。
新物品如果訓練時沒出現，模型不能直接查詢它的 embedding。
說明重點

這一頁可以提醒學生：

矩陣分解不是推薦系統的終點。

現代推薦系統通常會結合：

content-based features
deep learning
graph methods
sequence models
retrieval / ranking / re-ranking pipeline

SVD 和 matrix factorization 是理解推薦系統的基礎，但不是全部。

Slide 36: 最後總結
投影片內容

本單元三個核心觀念：

推薦系統可以表示成矩陣問題。
SVD 可以找出矩陣中的主要潛在方向。
推薦分數可以透過 user embedding 與 item embedding 的內積計算。

補充：

SVD 是理解推薦系統的好入口；
真實系統通常會使用 weighted matrix factorization、WALS 或更複雜的模型來處理稀疏資料。

說明重點

最後可以用一句話收尾：

SVD 的價值不只是分解矩陣，而是讓我們用較低維的向量空間理解使用者與物品之間的隱藏關係。
