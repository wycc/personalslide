{{溫和}} 接著我們先把推薦系統的問題講清楚。它真正想回答的，不是「現在最紅的電影是哪一部」，而是「某個使用者還沒看過哪些電影，但可能會喜歡」。這個差別很重要，因為熱門不一定適合每個人。就像大家都說某家餐廳好吃，但你如果不吃辣，推薦麻辣鍋給你就不一定有用。
畫面右上角有一個小例子。User A 看過《黑暗騎士：黎明昇起》和《記憶拼圖》。User B 也看過這兩部，另外還看過《佳麗村三姊妹》。User C 則看過《哈利波特》和《史瑞克》。所以問題來了：User A 還沒看過《佳麗村三姊妹》，系統應不應該推薦呢？
{{強調}} 直覺上，如果 User A 和 User B 的觀看紀錄很像，代表他們的口味可能接近。那麼 User B 喜歡、但 User A 還沒接觸過的電影，就變成一個合理的候選推薦。下方的流程圖也在說同一件事：先比較使用者之間的相似度，再把相似使用者看過的項目，推測成可能適合目標使用者的選項。這就是個人化推薦的起點。
