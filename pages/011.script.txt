{{溫和}} 接著我們真的替 User A 算一次推薦分數。User A 的偏好向量是零點八、零點五，可以想成他對第一個特徵的偏好比較強，第二個特徵也有一點喜歡。計算方式很單純，就是把 User A 的兩個數字，分別乘上每部電影的兩個特徵，再加總起來。
先看《黑暗騎士》，零點八乘零點七，加上零點五乘零點七，得到零點九一。這代表它跟 User A 的方向很接近，所以分數最高。再看《記憶拼圖》，零點八乘零點八，再加上零點五乘負零點五，最後是零點三九，也算是正向匹配。
其他電影就比較沒那麼適合。《哈利波特》算出負零點零五，幾乎接近不匹配；《史瑞克》是負零點三九；《Triplets》更低，是負零點五六。把分數由高到低排序，第一名是《黑暗騎士》，第二名是《記憶拼圖》。{{強調}} 不過推薦系統通常不會推薦使用者已經看過的電影。所以如果 User A 看過《黑暗騎士》，系統就會跳過它，改推薦下一個候選，也就是《記憶拼圖》。接下來，我們會把這種一部一部計算的方式，整理成更有效率的矩陣運算。
